# OpenRPA-JJC

> [!TIP]
> 🚀 **JJC 定制版** — 同步自 open-rpa/openrpa，开源 RPA 工具中文版

[![GitHub issues](https://img.shields.io/github/issues/open-rpa/openrpa.svg)](https://github.com/open-rpa/openrpa/issues)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](https://github.com/open-rpa/openrpa/blob/master/LICENSE)

**OpenRPA** 是一款开源的 RPA（机器人流程自动化）软件，支持 Windows 桌面应用自动化，可配合 OpenFlow 管理多个机器人。

---

## 功能简介

- 🤖 **开源免费**：完全开源，无需付费
- 🖥️ **Windows 自动化**：支持 Windows 桌面应用的自动化操作
- 🔄 **流程录制**：可视化流程设计器，支持录制和拖拽
- 🌊 **OpenFlow 集成**：配合 OpenFlow 管理多机器人集群
- 📹 **视频教程**：附完整视频教程，新手也能快速上手

---

## 安装步骤

### 方式一：下载安装包（推荐）

1. 下载 MSI 安装包：
   [点击下载 OpenRPA.msi](https://github.com/qmhdl1027/openrpa-JJC/releases/latest/download/OpenRPA.msi)

2. 双击运行，按提示完成安装

3. Windows 11 如果无法启动，尝试下载 Python 3.11 版本：
   [点击下载 OpenRPA.py.3.11.4.msi](https://github.com/open-rpa/openrpa/releases/latest/download/OpenRPA.py.3.11.4.msi)

### 方式二：从源码构建

\\\ash
git clone https://github.com/open-rpa/openrpa.git
cd openrpa
# 详见官方构建文档
\\\

---

## 快速开始

1. 安装后运行 **OpenRPA**
2. 首次使用需注册 **OpenFlow** 账号（免费）：
   [注册 OpenFlow 账号](https://app.openiap.io)
3. 登录后即可开始设计自动化流程
